Exhibit OptiPy

OptiPy

Undergraduate thesis, DLSU-Dasmariñas

Status
Completed
Classification
Energy, software, research
Access
Open

OptiPy tackles the energy use and carbon emissions caused by inefficient software. It pairs automated code optimization with execution-free carbon tracking in one platform. The system uses Abstract Syntax Tree refactoring, and TrOCR to turn images of code into optimized digital versions while estimating their environmental impact. The goal is to make sustainable programming a habit by giving developers actionable feedback on their code.

Technology
Python, CPython parser, abstract syntax trees, a CodeCarbon-inspired static analyzer, TrOCR, Halstead metrics, bytecode inspection, NumPy
